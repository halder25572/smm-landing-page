# SMM Landing Page

A modern and fully responsive landing page developed based on the provided Figma design.

## 🚀 Live Demo

[Live Website](https://smm-landing-page-ten.vercel.app)

## 📂 GitHub Repository

[GitHub Repository](https://github.com/halder25572/smm-landing-page)

## 🛠️ Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## ✨ Features

- Pixel-perfect implementation based on the provided Figma design
- Fully responsive design
- Smooth animations and micro-interactions
- Clean and maintainable component structure
- Optimized images and assets
- Modern UI and user experience

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/halder25572/smm-landing-page.git
cd smm-landing-page
npm install
npm run dev
```
